## 2. 启动初始化流程

```mermaid
flowchart TD
    A[startboot.onLoad] --> B[读取 URL 参数 level]
    B --> C[LogicSystem.init]
    C --> D[注册 PlanetService]
    D --> E[PlanetService.init]
    E --> F[监听 resetGame / PlanetBodyPositionChanged]
    C --> G{level == 3?}
    G -->|是| H[initStar]
    H --> I[检查 PlanetService 是否已注册]
    I --> J[preloadScene star]
    J --> K[loadScene star]
    K --> L[进入 star.scene]
    L --> M[PlanetItem / StarItem onLoad 自注册]
    L --> N[PlanetUI.start 同步面板]
    L --> O[SkyController.start 初始化 geometryRenderer]
```

## 3. 行星系统运行流程

```mermaid
flowchart TD
    A[编辑状态 Normal] --> B[用户调整质量/速度/位置/显示参数]
    B --> C[PlanetUI / PlanetPropertyItem 更新数据]
    C --> D[点击 开始模拟]
    D --> E[PlanetService.start]
    E --> F[记录初始位置]
    F --> G{有恒星?}
    G -->|有| H[给所有行星计算绕恒星圆轨道初速度]
    G -->|无| I{是否双星?}
    I -->|是| J[双星初速度计算]
    I -->|否| K{是否三星模式?}
    K -->|是| L[三星绕质心初速度计算]
    K -->|否| M[仅保留用户填写初始速度]
    H --> N[updateAllForce]
    J --> N
    L --> N
    M --> N
    N --> O[进入 Stimulate]
    O --> P[SkyController.update]
    P --> Q[PlanetService.update]
    Q --> R[固定步长物理积分]
    R --> S[PlanetItem.updateState]
    S --> T[轨迹/力箭头/质心可视化]
```

## 4. 固定步长与 Verlet 物理更新流程

```mermaid
flowchart TB
    A[PlanetService.update dt] --> B[_accumulator += dt]
    B --> C{_accumulator >= FIXED_DT?}
    C -->|否| Z[结束本帧]
    C -->|是| D[physicStep FIXED_DT]
    D --> E[半步速度更新 v += a * h/2]
    E --> F[位置更新 p += v * h]
    F --> G[重新计算所有引力]
    G --> H[得到新加速度 a_new]
    H --> I[再半步速度更新 v += a_new * h/2]
    I --> J[_accumulator -= FIXED_DT]
    J --> C
```

## 5. 引力计算分支图

```mermaid
flowchart TD
    A[calculateForce Planet] --> B{系统中有恒星?}
    B -->|有恒星| C[遍历所有恒星]
    C --> D[计算 planet 受 star 引力]
    D --> E[累加总力]
    B -->|无恒星| F[遍历其他行星]
    F --> G[计算 planet 受 otherPlanet 引力]
    G --> H[累加总力]
    E --> I[updateForce]
    H --> I
    I --> J[acceleration = force / mass]
```

## 6. 三星等角布局同步流程

```mermaid
flowchart TD
    A[编辑器中拖动某个行星] --> B[PlanetItem.onEditorTransformChanged]
    B --> C[PlanetService.onEditorPlanetPositionChanged]
    C --> D{允许编辑器同步?}
    D -->|否| Z[结束]
    D -->|是| E{无恒星且三星模式?}
    E -->|否| Z
    E -->|是| F[syncEqualAnglePlanetLayout]
    F --> G[确定锚点行星]
    G --> H[读取锚点半径与角度]
    H --> I[按 2π / 3 计算等角分布]
    I --> J[重排另外两颗行星位置]
    J --> K[缓存同步后位置]
```

## 7. UI 与事件交互流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant UI as PlanetUI
    participant Item as PlanetPropertyItem
    participant Event as EventManager
    participant Service as PlanetService

    User->>UI: 点击开始模拟
    UI->>Service: gameState = Stimulate
    UI->>Service: start()

    User->>Item: 修改位置
    Item->>Event: Raise PlanetBodyPositionChanged
    Event->>Service: updateBodyPosition
    Service->>Event: Raise PlanetUpdated
    Event->>UI: syncPanels

    User->>UI: 点击重置
    UI->>Event: Raise resetGame
    Event->>Service: resetGameToInitialPosition
    Service->>Event: Raise PlanetUpdated
    Event->>UI: syncPanels
```

## 8. 相机选择与聚焦流程

```mermaid
flowchart TD
    A[鼠标左键点击场景] --> B[FreeCameraController.tryPickPlanet]
    B --> C[Camera.screenPointToRay]
    C --> D[PhysicsSystem.raycast]
    D --> E{命中行星?}
    E -->|否| F[如果当前未聚焦则清空选择]
    E -->|是| G[PlanetService.setCurrentPlanet]
    G --> H[显示选中特效]
    H --> I[Raise FocusPlanetChanged]
    I --> J[PlanetUI 更新 focusLabel]

    K[用户按 F] --> L{已有 currentPlanet?}
    L -->|否| Z[结束]
    L -->|是| M{当前已聚焦?}
    M -->|否| N[设置 focusTarget]
    N --> O{聚焦模式}
    O -->|LookAt| P[相机只朝向目标]
    O -->|Follow| Q[相机沿 质心->行星 方向跟随]
    M -->|是| R[clearFocus]
```

## 9. 重置流程

```mermaid
flowchart TD
    A[用户点击重置] --> B[PlanetUI 设置 gameState = Normal]
    B --> C[关闭三星模式]
    C --> D[Raise resetGame]
    D --> E[PlanetService.resetGameToInitialPosition]
    E --> F[恢复所有行星初始位置]
    F --> G[速度归零]
    G --> H[清空轨迹]
    H --> I[销毁质心节点]
    I --> J[_simulationStarted = false]
    J --> K[UI 刷新]
```
