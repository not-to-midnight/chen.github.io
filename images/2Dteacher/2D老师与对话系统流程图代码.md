## 3. 对话加载与“节点注册”流程

```mermaid
flowchart TD
    A[外部 JSON 对话数据] --> B[DialogueManager.loadDialogue]
    B --> C[DialogueDataImpl.fromJSON]
    C --> D[把 json.nodes 转成 Map<string, DialogueNode>]
    D --> E[DialogueDataImpl.validate]
    E --> F{校验通过?}
    F -->|否| G[输出错误并返回 null]
    F -->|是| H[存入 _dialogues: Map<string, DialogueData>]
    H --> I[RaiseEvent DialogueLoaded]

    style D fill:#eef6ff
    style H fill:#eef6ff
```

### 说明

这里的“注册节点”本质上不是注册节点类型，而是：

- 把整段对话资源注册进 `DialogueManager`
- 节点作为 `Map<string, DialogueNode>` 中的条目存在

## 4. 对话启动与节点推进流程

```mermaid
flowchart TD
    A[startDialogue dialogueId] --> B{当前是否已有对话在播放?}
    B -->|是| Z1[拒绝启动]
    B -->|否| C[从 _dialogues 查找 DialogueData]
    C --> D{对话存在?}
    D -->|否| Z2[报错返回]
    D -->|是| E[state = LOADING]
    E --> F[设置 _currentDialogue]
    F --> G[清空 _history]
    G --> H[loadDialogueResources]
    H --> I[按 startNodeId 找到起始节点]
    I --> J[state = PLAYING]
    J --> K[RaiseEvent DialogueStarted]
    K --> L[playNode startNode]

    L --> M[checkConditions]
    M --> N{条件满足?}
    N -->|否| O[_playNextNode]
    N -->|是| P[executeActions]
    P --> Q[设置 _currentNode]
    Q --> R[记录 _currentNodeStartTime]
    R --> S[历史追加 node.id]
    S --> T[RaiseEvent NodeStarted]
    T --> U[若有 voiceClip 预留音频播放]
    U --> V[计算 duration]
    V --> W{自动播放且无选项?}
    W -->|是| X[_startAutoPlay]
    W -->|否| Y[等待继续/选项]
```

## 5. 对话分支与选项逻辑

```mermaid
sequenceDiagram
    participant 用户
    participant UI as DialogueUI
    participant DM as DialogueManager
    participant DC as DialogueConditionManager
    participant DA as DialogueActionManager

    用户->>UI: 点击某个选项
    UI->>DM: selectChoice(choiceId)
    DM->>DM: 查找当前节点 choices
    DM->>DC: checkConditions(choice.conditions)
    DC-->>DM: 条件通过/失败
    alt 条件通过
        DM->>DA: executeActions(choice.actions)
        DM->>DM: RaiseEvent ChoiceSelected
        DM->>DM: 根据 nextNodeId 找下一节点
        DM->>DM: playNode(nextNode)
    else 条件失败
        DM-->>UI: 返回 false
    end
```

## 8. 2D 老师播放链路

```mermaid
flowchart TD
    A[外部调用 teacher2DService.playAnimation] --> B[根据 Animation2DType 查配置]
    B --> C{配置存在?}
    C -->|否| Z1[返回 false]
    C -->|是| D{animationController 已注入?}
    D -->|否| Z2[返回 false]
    D -->|是| E[更新 animationState]
    E --> F[调用 controller.playAnimation]
    F --> G{当前模式}
    G -->|cc.Animation| H[buildCocosAnimController]
    G -->|sp.Skeleton| I[buildSpineController]
    H --> J[真正播放动画]
    I --> J
    J --> K[单次动作完成后触发 onComplete]
```

## 9. 对话参数驱动 2D 老师的推荐联动方案

flowchart TD

    B --> C[DialogueUI.showNode node]
    B --> D[DialogueTeacher2DBridge.onNodeStarted]

    E -->|否| F[不处理]

## 10. 基于动作系统驱动 2D 老师的方案

```mermaid
flowchart TD
    A[进入节点或点击选项] --> B[DialogueManager.executeActions]
    B --> C[DialogueActionManager.executeAction]
    C --> D{action.type == playAnimation?}
    D -->|否| E[执行其他动作]
    D -->|是| F[解析 action.key / action.value]
    F --> G[获取 teacher2DService]
    G --> H[播放对应 2D 老师动作]
```

## 12. 统一系统的完整时序图

```mermaid
sequenceDiagram
    participant 数据 as Dialogue JSON
    participant DM as DialogueManager
    participant EV as EventManager
    participant UI as DialogueUI
    participant Bridge as DialogueTeacher2DBridge
    participant TS as teacher2DService
    participant Item as teacher2DItem

    数据->>DM: loadDialogue(data)
    DM->>DM: fromJSON + validate
    DM->>EV: Raise DialogueLoaded

    用户->>DM: startDialogue(dialogueId)
    DM->>DM: 找到 startNode
    DM->>EV: Raise DialogueStarted
    DM->>DM: playNode(startNode)
    DM->>EV: Raise NodeStarted(node)

    EV->>UI: onNodeStarted(node)
    UI->>UI: showNode + 打字机

    EV->>Bridge: onNodeStarted(node)
    Bridge->>TS: playAnimation(mappedType)
    TS->>Item: controller.playAnimation(...)
    Item-->>TS: onComplete（单次动作时）

    用户->>UI: 点击继续/选择分支
    UI->>DM: playNextNode / selectChoice
    DM->>EV: Raise NodeStarted(nextNode)

    DM->>EV: Raise DialogueEnded
    EV->>Bridge: onDialogueEnded
    Bridge->>TS: playIdle1()
```
